# batch-resultados

Branch de dados, sem código: cada execução do batch noturno em COBOL da
[pix-api](https://github.com/RafaelNicolauiOS/pix-api) é publicada aqui pelo GitHub Actions.

- `indice.json`: lista das execuções (mais recente primeiro)
- `execucoes/<id>/`: `MOVIMENTO.DAT` (entrada), `RESULTADO.DAT`, `RELATORIO.TXT`, `JOBLOG.TXT` e `execucao.json`

Painel: https://rafaelnicolauios.github.io/pix-api/batch.html
