Processamento noturno

Um batch em COBOL confere, conta a conta, se o razão contábil (cada crédito e débito registrado pela API em Java) fecha com os saldos. É a conciliação que bancos rodam toda madrugada para pegar dinheiro criado ou perdido.

  • Java · Spring Boot
  • COBOL · GnuCOBOL
  • GitHub Actions
  • JavaScript

    1. ExtraiSTEP010 · GET /batch/movimento
    2. ValidaHeader, trailer e totais de controle
    3. SORTRazão por conta, data e hora
    4. ConciliaBalance line razão × saldo
    5. PublicaSTEP030 · relatório e painel
